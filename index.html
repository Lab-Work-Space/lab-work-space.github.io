Labworkspace

Labworkspace makes two developer tools, Labelfence and Crewlatch. Each has a free lite edition with its source on GitHub, and a full edition you can buy.

Labelfence

Labelfence is a command-line tool that audits an object-detection dataset before you train on it. The lite edition checks YOLO datasets: every image and every label file, against the rules of the format. It runs offline and never changes your dataset. The full edition is 29 USD.

  • Labelfence page
  • Lite edition on GitHub
  • Full edition on Gumroad

Crewlatch

Crewlatch is a process for Claude Code. Your request goes through stages, and each stage ends in a checkpoint you can resume from. The lite edition is one skill and four agents. The full edition has twelve agents and two security gates, and costs 29 USD.

  • Crewlatch page
  • Lite edition on GitHub
  • Full edition on Gumroad
