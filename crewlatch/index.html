Crewlatch

Crewlatch is a process for getting work through Claude Code agents: one orchestration skill that runs your request through stages, agents that do the work of each stage, and a checkpoint after every stage so that you can resume interrupted work. The lite edition is free.

What is in which edition. The lite edition has one skill and four agents (pm, backend, tester and document), and runs five stages with a checkpoint after each. The full edition has twelve agents and adds two security gates, a retro, and classification of the request. Whatever is marked (full edition) below is not in the lite edition.

What the process is

The main Claude Code session runs the skill. It dispatches agents, asks you questions, and records what happened. The agents do not talk to you and do not dispatch each other.

The stages the lite edition runs, in order:

  • Agree the goal: Claude asks its questions one at a time and ends with a short spec that you approve.
  • Plan: the pm agent writes tasks with owners, dependencies and acceptance criteria.
  • Build: the backend agent builds one task per dispatch.
  • Test: the tester agent checks the result against your original request. Defects go back to the build stage at most three times, then Claude asks you.
  • Document: the document agent updates the project docs and the Project Book.

Claude says which stages it will run, and skips any that the task does not need. The full edition adds:

  • Classification of the request (full edition): the stages are chosen by request type, such as a bug fix, a documentation change, a performance task, a release check or a new feature.
  • Security gate 1 (full edition): the spec is reviewed before any code exists.
  • Security gate 2 (full edition): the code is audited before release.
  • A retro (full edition): lessons become proposed rules, and you approve, edit or reject each one.

After every stage a checkpoint file records the stage table, the pending tasks and what is waiting for you. When you run the skill again, it asks whether to resume the unfinished work or start the new request. It never resumes silently.

The process uses more tokens than a single session, because several agents each read context and do their own work. For a small task, work without it.

Install the lite edition

The lite edition holds one skill, team-dev, and four agents: pm, backend, tester and document. It also installs five templates, a token policy and a manifest that lists every file it wrote. It needs Claude Code and bash, and downloads nothing. Tested on macOS. Linux and Windows have not been tested.

Download the zip from the releases page of the crewlatch-lite repository, unzip it and go into the folder. Then:

./install.sh --dry-run   # see what would change
./install.sh             # install into ~/.claude

If you already have files with the same names, the installer stops and changes nothing. ./install.sh --force replaces them and keeps a backup of each. If ./install.sh reports a permission error, run bash install.sh. Use one edition per ~/.claude folder.

Start a new Claude Code session in a project folder and type:

Use the team-dev skill. Add a /health endpoint that returns the build version.

Claude says which stages it will run, asks its questions one at a time, and writes a checkpoint to ~/.claude/team/state/<project>.md after each stage. To continue later, type Use the team-dev skill. Resume.

To remove the lite edition, run ./uninstall.sh from the folder of the version that is installed. Your checkpoints and Project Books are kept, and so are files you edited.

Free collections of agents

Free collections of agents exist on GitHub. Crewlatch is a process, not a list.

What the full edition adds

The full edition has twelve agents, adding sa, security, frontend, database, ai-prompt, devops, git and optimizer. It adds the two security gates, stage selection by request type, the retro, and a guide with a worked example. It costs 29 USD: Crewlatch on Gumroad.
