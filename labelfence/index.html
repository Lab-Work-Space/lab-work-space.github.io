Labelfence

Labelfence is a command-line tool that audits object-detection datasets before you train on them. The lite edition is free and reads datasets in YOLO format. It prints what it found, writes a JSON report, and exits with a code a script can test. It runs offline and never changes your dataset.

What the lite edition checks

It reads three YOLO layouts: images/<split>/ with labels/<split>/ (the Ultralytics layout), <split>/images/ with <split>/labels/, and a flat images/ with labels/. A data.yaml with names and nc is read when it exists.

For every label line it checks the field count, the numbers, the class id, that the box lies inside the image, that it has a size, and that it is not repeated. For every image it checks that the file is readable, its size, its extension, its name, and that a label file exists.

The lite edition reports 20 kinds of finding, each with a stable code: 9 codes starting with E_ are errors and 11 starting with W_ are warnings. Examples are E_BOX_OUT_OF_RANGE, E_CLASS_ID_INVALID, W_IMAGE_WITHOUT_LABEL and W_CLASS_IMBALANCE. labelfence stats prints counts per split and per class.

Install

You need Python 3.10 or newer, git and a network connection. Install into a virtual environment:

python3 -m venv .venv
. .venv/bin/activate
pip install "git+https://github.com/Lab-Work-Space/labelfence-lite@v1.0.0"

Check the install:

labelfence --version
labelfence 1.0.0

To remove it later, run pip uninstall -y labelfence.

Quick start

labelfence sample writes a small synthetic dataset to try the tool on. The case faulty holds one example of every code the lite edition reports.

labelfence sample --out demo --case faulty

Audit it:

labelfence audit demo

The command prints a summary and the findings grouped by code, writes demo-audit.json in the current folder, and exits with code 3 because the dataset has errors. These are some of the lines it prints, summary first; the last line goes to standard error:

Labelfence 1.0.0: demo
Format: yolo (layout: ultralytics)
Images: 23  Boxes: 91  Classes: 4
  train: 23 images, 91 boxes, 3 without boxes
Findings: 9 errors, 12 warnings
  E_BOX_OUT_OF_RANGE: 1
  W_IMAGE_NAME_COLLISION: 2
E_BOX_OUT_OF_RANGE (1): a box value is outside the image or outside 0 to 1
  labels/train/outofrange.txt:2  line 2: field 4 is outside 0 to 1.
labelfence: error: the audit found 9 errors.

Exit code 3 with that last line is the expected result for a dataset that has errors: it is how a script learns that the audit found something, not a failure of the tool.

The case clean has no finding, and the audit exits with code 0:

labelfence sample --out clean --case clean
labelfence audit clean
Findings: 0 errors, 0 warnings

Audit your own dataset the same way, with labelfence audit path/to/dataset. Add --strict to exit with code 3 on warnings as well, and --quiet to print the summary only. Pass --report FILE to choose where the JSON report goes.

Exit codes

CodeMeaning
0No finding, or warnings only
1Unexpected error
2Usage error, a command that belongs to the full edition, or an output that cannot be written
3The audit found errors (or warnings with --strict)
5Unsupported or invalid input: not a dataset, or a layout that cannot be read
130Interrupted; temporary files are removed

What the lite edition does not do

  • It reads the header of an image and does not decode it. A JPEG that is cut off after its header is not found.
  • It reads YOLO datasets and boxes only. A polygon label is a finding unless you pass --allow-polygons, which takes the bounding box of the polygon.
  • It never modifies your dataset, never writes inside it, and never replaces an existing file unless you pass --overwrite.
  • Tested on macOS with Python 3.10 and 3.14. Linux and Windows have not been tested.

It reports what it finds and you decide what to change. It makes no claim about training results.

Free tools that do parts of this

Ultralytics checks labels itself when training starts, FiftyOne can inspect and export datasets, and Datumaro can inspect, validate and convert them, and Roboflow has online dataset tools; use them when they fit your workflow.

What the full edition adds

The full edition reads COCO and Pascal VOC datasets as well, converts between the three formats with a read-back check, finds look-alike images that sit on both sides of a train and validation split, writes split lists and an HTML report, and includes a catalogue of faulty datasets and pytest fixtures. It costs 29 USD: Labelfence on Gumroad.

In the lite edition the commands dupes, split, convert and html-report appear in labelfence --help; each prints a message that it belongs to the full edition and exits with code 2.

The source of the lite edition is in the labelfence-lite repository, under the MIT licence.
